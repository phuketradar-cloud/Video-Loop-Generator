Loop Quality Score

เกี่ยวกับเครื่องมือนี้ / ขอบเขตที่ทำจริงเทียบกับสเปกเต็ม

เครื่องมือนี้ implement ตาม Pipeline ที่ระบุ (Metadata Analysis → Motion Profile → Loop Candidate Detection ทั้งคลิป → Candidate Scoring → Strategy Selection → Adaptive Transition → Color Matching → Seam Blending → Quality Check → Automatic Retry → Long-Video Generation) แบบ client-side ล้วน ๆ ในเบราว์เซอร์ ตามที่เลือกไว้ (ไม่มี server/backend) จึงมีส่วนที่ต้อง "แปล" จากสเปกต้นฉบับ:

  • Optical Flow: ใช้ block-based motion estimation ของ Canvas เอง (regional shift ต่อกริด) แทน Farneback/TV-L1/RAFT จริง — เป็นการประมาณ ไม่ใช่ dense optical flow
  • Frame Interpolation: ใช้ motion-compensated blending หลายขั้นระหว่างช่วง transition แทนโมเดล AI interpolation (RIFE ฯลฯ)
  • FFmpeg / OpenCV / REST API / Job Queue / Storage: ไม่ได้ implement เพราะเลือก deploy แบบ static site ไม่มี server — encode ผ่าน Canvas + MediaRecorder ของเบราว์เซอร์แทน FFmpeg
  • Color/Exposure Matching: ทำจริงด้วยการวัดค่าความสว่าง/สี RGB เฉลี่ยของช่วงต้น-ท้าย แล้วปรับผ่าน canvas filter ระหว่างการผสาน
  • Quality Scoring + Automatic Retry: ทำจริง — ลองหลาย strategy/duration แล้ววัดคะแนนก่อนเลือกตัวที่ดีที่สุด

AI-Assisted Seamless Video Loop Engine — full pipeline spec (23 sections / 11 phases): metadata analysis, scene/shot detection, motion analysis, frame similarity, loop candidate detection across the whole clip (not just edges), weighted candidate scoring, multiple loop strategies (forward / crossfade / forward+reverse / motion-matched) with automatic selection, adaptive transition duration by motion level, optical flow, frame interpolation, color/exposure matching, seam detection + quality scoring, automatic retry across parameters, long-video generation with anti-repetition variation, FFmpeg/OpenCV backend, REST API + job queue, processing modes (FAST/BALANCED/HIGH QUALITY/AI QUALITY), editable loop points UI.
